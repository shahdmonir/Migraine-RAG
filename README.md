# Migraine RAG — نظام سؤال وإجابة طبي عن الصداع النصفي

نظام RAG (Retrieval-Augmented Generation) بيجاوب على أسئلة عن الصداع النصفي بالاعتماد **حصرياً** على دليل NICE CG150 الرسمي، مع توثيق كامل لكل إجابة (المصدر، الصفحة، النص المقتبس)، وطبقات أمان متعددة، ولوحة تقييم بتقيس أداء النظام بأرقام حقيقية.

---

## المميزات الرئيسية

- **إجابات موثقة بالكامل**: كل إجابة معاها رقم الصفحة والنص المقتبس بالحرف من الدليل، مع زرار "المصدر" بيفتح الـ PDF الأصلي ويظلل مكان الإجابة بالظبط.
- **دعم كامل للعربي والإنجليزي**: الواجهة والإجابات بتتبع لغة السؤال تلقائياً.
- **نظام محادثات متعددة**: Sidebar بيحفظ كل محادثاتك، بإمكانية البحث والحذف.
- **طبقات أمان متعددة**:
  - فلتر Regex لكشف محاولات الاختراق (Prompt Injection)
  - بوابة ثقة (Confidence Threshold) بترفض الإجابة لو الدليل المسترجع بعيد عن السؤال
  - تمييز بين الأسئلة العامة (بيجاوب عليها) والأسئلة الشخصية/الجرعات (بيرفض ويحوّل لطبيب)
- **قابلية التفسير (Explainability)**: كل عملية بحث بتتسجل بالكامل (كل المقاطع المسترجعة + درجة تطابقها)، وتقدري تشوفيها من زرار "تفاصيل الاسترجاع" تحت أي إجابة.
- **لوحة تقييم (Evaluation Dashboard)**: مقاييس حقيقية محسوبة من مجموعة اختبار ثابتة (Test Set): درجة الأمان، درجة الإجابة، دقة التوثيق، دقة الاسترجاع (Precision@K)، والالتزام بالمصدر (Faithfulness).
- **وضع ليلي/نهاري** قابل للتبديل.

## 0) المتطلبات قبل ما تبدئي

- **Python 3.10+** مثبت
- **Node.js 18+** مثبت (عشان الفرونت اند)
- **مفتاح Gemini API** مجاني من [Google AI Studio](https://aistudio.google.com/app/apikey)

> ⚠️ **ملحوظة عن الحد اليومي (Quota)**: النسخة المجانية من Gemini API فيها حد يومي محدود جداً (حوالي 20 طلب/يوم لكل موديل). لو استخدمتيه بكثافة (شات + `evaluate.py` في نفس اليوم)، ممكن يقفل مؤقتاً ويرجع تلقائياً بعد 24 ساعة.

## 1) حطي ملف الـ PDF

نزّلي دليل NICE CG150 من الرابط الرسمي:
```
https://www.nice.org.uk/guidance/cg150/resources/headaches-in-over-12s-diagnosis-and-management-pdf-35109624582853
```

سميه `source.pdf` وحطيه هنا بالظبط:
```
backend/data/source.pdf
```

---

## 2) شغّلي الـ Backend

افتحي Terminal جوه VS Code وادخلي على مجلد الـ backend:

```bash
cd backend
python -m venv venv
```

فعّلي الـ virtual environment:

- **ويندوز (PowerShell):** `.\venv\Scripts\Activate.ps1`
- **ماك/لينكس:** `source venv/bin/activate`

ثبتي المكتبات:

```bash
pip install -r requirements.txt
```

انسخي ملف `.env.example` وسميه `.env`:

```bash
cp .env.example .env
```

افتحي `.env` وحطي فيه:

```env

هيديكي رابط زي:
```
http://localhost:5173

افتحيه في المتصفح.

## 4) تقييم النظام (اختياري بس موصى بيه)

عشان تشوفي أرقام حقيقية عن أداء النظام (درجة الأمان، دقة الاسترجاع، إلخ) في لوحة "التقييم"، شغّلي في ترمينال الـ backend:

```bash
python evaluate.py
```

هيشغّل الـ 16 سؤال بتوع `test_set.json` تلقائياً، ويحسب المقاييس، ويحفظهم في `evaluation_results.json`. بعد كده افتحي تبويب "لوحة التقييم" في الموقع.

> ⚠️ شغّليه لوحده من غير ما تستخدمي الشات في نفس اللحظة، عشان قيود الكوتة اليومية.

## 5) جربي

- اكتبي سؤال عن الصداع النصفي (بالعربي أو الإنجليزي)
- هتيجي الإجابة مع badge لدرجة الثقة (High/Medium/Low)
- دوسي على زرار **"المصدر"** — هيفتح الصفحة الأصلية من الـ PDF مع تظليل مكان الإجابة
- دوسي على زرار **"تفاصيل الاسترجاع"** — هيوريكي كل المقاطع اللي البحث رجّعها ونسبة تطابق كل واحد
- جربي سؤال شخصي (زي "أنا حامل، آخد إيه؟") — المفروض يرفض ويحوّلك لطبيب
- جربي سؤال برة الموضوع (زي "عاصمة اليابان؟") — المفروض يرفض بسبب بوابة الثقة

## ملاحظات مهمة

- لو غيّرتي الـ PDF، لازم تشغلي `python ingest.py` تاني عشان يعيد بناء قاعدة البيانات.
- الموديل المستخدم للتوليد هو **Gemini** (قابل للتغيير من `GEMINI_MODEL` في `.env`).
- الـ Embeddings شغالة **محلياً على جهازك** (موديل `paraphrase-multilingual-MiniLM-L12-v2`) — مجانية ومش محتاجة أي API key.
- لو ظهرلك خطأ CORS، اتأكدي إن الـ backend شغال على بورت **8000** بالظبط.
- المحادثات وسجل الاسترجاع بيتخزنوا محلياً في `backend/conversations.db` (SQLite).

## حدود معروفة (Known Limitations)

بشفافية كاملة، دي النقط اللي النظام لسه محتاج يتطور فيها:

- **الاعتماد الكامل على Gemini API**: لو الخدمة وقعت أو الكوتة خلصت، النظام بيتوقف عن الإجابة.
- **فلتر الأمان (Injection Guard) مبني على Regex** بشكل أساسي — طبقة حماية إضافية بالـ AI (بتستخدم Gemini نفسه لفهم محاولات اختراق أذكى) **مكتوبة بالكامل في الكود لكن معطّلة حالياً** بسبب محدودية الكوتة المجانية.
- **مقياس Faithfulness في لوحة التقييم تقريبي** (بيعتمد على تطابق كلمات مفتاحية مع مرادفات)، مش تحليل لغوي كامل للمعنى.
- **مجموعة الاختبار (Test Set) صغيرة نسبياً** (16 سؤال) — كافية للـ MVP لكن محتاجة توسيع لتغطية أشمل.

## قاموس مصطلحات سريع

| المصطلح | المعنى |
|---|---|
| **Chunking** | تقسيم الدليل لأجزاء صغيرة (350 كلمة، مع تداخل 40 كلمة) قابلة للبحث |
| **Embeddings** | تحويل النص لأرقام (Vectors) تمثل معناه |
| **Distance** | مقياس رقمي لبُعد/قرب معنى النص عن السؤال (كل ما قلّ، كان أقرب) |
| **Confidence Threshold** | حد أدنى لدرجة القرب، لو اتعدّاه بيترفض السؤال قبل ما يوصل للموديل |
| **Precision@K** | هل المعلومة الصحيحة كانت موجودة أصلاً ضمن أفضل K نتيجة من البحث |
| **Citation Accuracy** | هل رقم الصفحة اللي ذكره الموديل في إجابته صحيح فعلاً |

| **Faithfulness** | هل الإجابة بتغطي المعلومات المهمة المتوقعة من الدليل |
